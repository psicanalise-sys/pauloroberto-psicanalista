# Paulo Roberto — Psicanálise Online

Repositório do site profissional de Paulo Roberto Pereira da Cunha e da experiência guiada de autopercepção **A Estrada**.

## Estrutura

- `index.html` — site principal
- `assets/img/` — ativos visuais públicos do site
- `experiencias/a-estrada/` — experiência A Estrada e layout de devolutiva
- `docs/` — documentação técnica e operacional do repositório

## Fluxo de publicação

- `main` — produção / GitHub Pages
- `dev` — desenvolvimento e homologação

Alterações devem ser preparadas e revisadas em `dev` antes de qualquer merge para `main`.

## Privacidade

Este repositório não deve conter dados de pacientes, leads, respostas individuais da experiência, planilhas de CRM, tokens, senhas, chaves de API ou outros dados sensíveis.

## A Estrada

A Estrada é apresentada como experiência guiada de autopercepção. Não é teste psicológico nem instrumento diagnóstico. A matriz interpretativa permanece sujeita à validação de Paulo Roberto antes de uso clínico ou automatizado em produção.
