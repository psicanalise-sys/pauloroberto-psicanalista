# Documentação

Esta pasta concentra documentação técnica e operacional do site e da experiência A Estrada.

## Regras de segurança

- Não armazenar dados pessoais de leads ou pacientes no GitHub.
- Não versionar respostas individuais da experiência.
- Não versionar credenciais, tokens, senhas ou chaves de API.
- Mudanças em produção devem ser revisadas na branch `dev` antes de merge para `main`.
- Interpretações da experiência devem permanecer como hipóteses de autopercepção, sem diagnóstico, e dependem de validação de Paulo Roberto.
